## 扱いの区分

| 区分 | 意味 |
|---|---|
| そのまま移す | 新サイトに同じURLのページがある（転送不要） |
| 新URLへ301 | 旧URLを新サイトの別URLへ転送する |
| 統合して301 | 複数の旧ページを1つの新ページにまとめて転送する |
| **要確認** | 残す・統合・削除を管理者が決める。決まるまで301は書かない |
